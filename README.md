# Student Portal — Android Assignment 2

## Features
- Splash/welcome screen and explicit Activity navigation.
- Login screen with local demo credentials.
- Register form with required-field, email, password-length, and confirm-password validation.
- Forgot password and simulated reset-password flow.
- Dashboard grid with Modules, Assignments, Results, and Timetable cards.
- Profile screen and Logout.
- Java Activities with XML layouts; ConstraintLayout, LinearLayout, and GridLayout are demonstrated.
- Default colors/strings and night-mode colors resources.

## Demo login
- Email: `student@example.com`
- Password: `123456`

Authentication and password recovery are local simulations. No backend or real email is used.

## Navigation
Splash → Login → Dashboard → Profile → Logout/Login.
Login → Register → Login.
Login → Forgot Password → Reset Password → Login.

## Run
Open this folder in Android Studio, allow Gradle sync, then run the `app` configuration on an emulator or connected Android device.
